# The Quake Archivist's Handbook

## Checkout

```bash
git clone --recurse-submodules git@github.com:Jason2Brownlee/QuakeArchivistsHandbook.git
```

## Local Website

```bash
cd QuakeArchivistsHandbook
hugo server
```

Then visit `http://localhost:1313`
