### **Chapter 14. Publish the archive**

Teach the learner how to turn the working archive into a public resource.

Topics include:

- Preparing the README and project description.
- Publishing on GitHub or another suitable platform.
- Organising Markdown documentation.
- Publishing downloadable files.
- Linking releases to their supporting evidence.
- Creating navigable indexes.
- Making the archive searchable.
- Providing clear download instructions.
- Documenting known gaps and uncertainties.
- Including credits and acknowledgements.

Also cover practical considerations:

- Hosting costs and storage limits.
- File size restrictions.
- Large files and external download hosting.
- Copyright and redistribution permissions.
- Maintaining original filenames and file contents.
- Backups and repository maintenance.

**Outcome:** The learner has a publicly accessible archive that others can use and contribute to.
