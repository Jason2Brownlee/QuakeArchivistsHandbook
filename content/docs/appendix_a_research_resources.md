# Appendix A: Research Resources

This appendix contains a collection of web resources that can help you research, recover and document files for your Quake archive.

The resources include historical websites, file archives, software collections, discussion forums and other useful research tools.

These links are intended as starting points for your own investigations. Given the age and changing nature of many of these websites, some links may no longer work or may become unavailable in the future. Even when a website is no longer active, archived copies or references elsewhere may still prove useful.

## Internet Archive

The Internet Archive is a digital library that preserves historical websites, software, books, videos and other digital material. It is an important resource for Quake archiving, particularly when researching original project websites, recovering old files and investigating historical software collections.

* [Internet Archive](https://archive.org/)\
`https://archive.org/`\
Search and access archived digital material, including software collections, CD-ROM images and historical files.

* [Wayback Machine](https://web.archive.org/)\
`https://web.archive.org/`\
View historical captures of websites to recover old project pages, announcements, download links and other information. Particularly useful for researching defunct Quake websites and identifying files that were once available for download.

* [Wayback Machine CDX Server API](https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server)\
`https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server`\
Documentation and source code for the CDX Server API, which provides programmatic access to indexes of archived web captures. Useful for discovering historical URLs, enumerating archived website content and identifying old download links that may not be easily found through the Wayback Machine interface.

* [Wayback Machine APIs](https://archive.org/help/wayback_api.php)\
`https://archive.org/help/wayback_api.php`\
Documentation for APIs that provide programmatic access to Wayback Machine services. Useful for checking whether historical URLs have archived captures and automating research into old Quake websites and download locations.

## Quake Gaming News

During the 1990s and early 2000s, several websites published regular news about Quake, including modification releases, updates, developers, community events and download locations. Their historical news archives can be particularly useful for establishing release dates and discovering files that are no longer available elsewhere.

* [Blue's News](https://www.bluesnews.com/)\
`https://www.bluesnews.com/`\
One of the longest-running PC gaming news sites, originally established as a Quake news site in 1996. Still active, with an extensive searchable historical news archive.

* [ShugaShack / ShackNews](http://www.shacknews.com/)\
`http://www.shugashack.com/`, `http://www.shacknews.com/`\
Originally known as Quake Hole and then sCary's Shuga' Shack, it covered Quake and PC gaming news. It later became Shacknews. Historical material from its early Quake coverage may be accessible through the Internet Archive.

* [Quake2.com](http://www.quake2.com/)\
`http://www.quake2.com/`\
A historical Quake 2 community website that hosted modification projects, developer pages and other Quake 2 resources. Particularly useful for researching older modifications, identifying original project websites and recovering historical download links. The original website is no longer reliably accessible, but historical pages may be available through the Wayback Machine.

* Redwood's Quake News\
`http://redwood.gatsbyhouse.com/`, `http://redwood.stomped.com/`\
An important early Quake news site covering releases, community developments and other Quake-related news. No longer active. Historical pages may be accessible through the Internet Archive.

* Stomped\
`http://www.stomped.com/`\
A major early Quake community website featuring news, information and file downloads. No longer active. Historical pages may be accessible through the Internet Archive.

* Telefragged\
`http://www.telefragged.com/`\
A major Quake community website and hosting service. Its hosted project sites and news content can provide useful historical information about modifications and their releases. No longer active in its original form. Historical pages may be accessible through the Internet Archive and other Quake archives.

* Frag.com\
`http://www.frag.com/`\
A historical gaming news and community resource. No longer active. Historical pages may be accessible through the Internet Archive.

**Research note:** For sites that are no longer active, try searching the Internet Archive using both the original domain and specific historical page URLs.

## Developer .plan Archives

During the 1990s, game developers sometimes published updates through Unix `.plan` files, sharing development progress, technical information, project announcements and personal commentary. Historical collections of these files can provide useful evidence about Quake development, modifications, release dates and related projects.

* [Gamers.org Developer .plan Archive](https://www.gamers.org/pub/archives/plans/)\
`https://www.gamers.org/pub/archives/plans/`\
A collection of historical `.plan` updates from id Software developers and others, including records from John Carmack, John Romero and developers associated with other game studios.

* [John Carmack .plan Archive](https://github.com/oliverbenns/john-carmack-plan)\
`https://github.com/oliverbenns/john-carmack-plan`\
A collection of John Carmack's historical `.plan` entries, organised into readable Markdown files.

## Web Search Engines

General-purpose search engines are useful for discovering surviving Quake websites, download mirrors, developer pages, historical references and individual files. Different search engines maintain different indexes, so searching across several services can reveal results that others miss.

* [Google](https://www.google.com/)\
`https://www.google.com/`\
A widely used search engine with extensive coverage of websites, documents and downloadable files.

* [Yandex](https://yandex.com/)\
`https://yandex.com/`\
An alternative search engine that may find websites and files not returned by Google or other search engines.

* [DuckDuckGo](https://duckduckgo.com/)\
`https://duckduckgo.com/`\
A general-purpose search engine that provides another independent set of search results.

* [Bing](https://www.bing.com/)\
`https://www.bing.com/`\
Microsoft's search engine, useful for finding websites, archived references and downloadable files.

## FTP Search Engines

FTP search engines index files and directory listings from public FTP servers. They can help locate known Quake modification filenames, discover alternative download locations and find releases that are not indexed by general-purpose search engines. Some results link directly to FTP servers, which may require an FTP client such as FileZilla to access.

* [FileMood](https://filemood.com/)\
`https://filemood.com/`\
Search for files across indexed FTP servers and other file repositories. Useful for locating specific filenames and alternative copies of known releases.

* [Mamont's Open FTP Index](https://www.mmnt.net/)\
`https://www.mmnt.net/`\
Search indexed public FTP directory listings for files and folders. Particularly useful for discovering files stored in historical FTP archives and mirrors.

## Usenet and Discussion Archives

* [Google Groups](https://groups.google.com/)\
`https://groups.google.com/`\
Search archived Usenet discussions for project names, developers, release announcements and download references.

## Quake Mailing List Archives

During the early years of Quake, developers and enthusiasts used email mailing lists to discuss game development, QuakeC programming, technical problems and modification projects. Archived discussions can provide useful historical evidence, including development techniques, references to early modifications, release announcements and links to files that may no longer be available elsewhere.

* [Quake Developers Mailing List (quake-dev)](https://www.gamers.org/dEngine/quake/archive/)\
`https://www.gamers.org/dEngine/quake/archive/`\
An archive of discussions from the Quake Developers Mailing List, covering March to August 1996. Useful for researching early Quake development, technical discussions and community projects.

* Quake-C Mailing List Archives\
`http://www2.csn.net/~rudeseal/quakec/list.html`\
An archive of QuakeC programming discussions from July to August 1996. Useful for investigating early modification development, programming techniques and problems encountered by QuakeC developers.

**Research note:** The original Quake-C Mailing List website is no longer active. Access its archived pages through the Wayback Machine.

## CD-ROM and Software Collections

Resources for finding Quake modifications distributed on magazine cover CDs, shareware compilations and other historical media.

* [BetaArchive](https://www.betaarchive.com/)\
`https://www.betaarchive.com/`\
A community dedicated to preserving historical software, including beta releases, development builds, abandonware and original software distributions. Particularly useful for researching early and unreleased game versions, identifying historical software releases and locating rare files. The site also maintains discussion forums where collectors share information and research. Access to downloadable files requires membership and archive access approval.

* [QuakeDiscs](https://quakediscs.com/)\
`https://quakediscs.com/`\
A catalogue of historical Quake add-on CDs, including disc contents and file listings. Useful for identifying modifications and other files distributed on magazine cover CDs and commercial compilations. It is a catalogue rather than a complete collection of downloadable CD images, so use it to identify discs and files to investigate elsewhere.

* [DiscMaster](https://discmaster.textfiles.com/)\
`https://discmaster.textfiles.com/`\
Search filenames and indexed content from historical CD-ROM and floppy disk collections preserved by the Internet Archive. Particularly useful for locating Quake modifications, utilities and other files without needing to know which disc contains them.

* [CD.textfiles.com](http://cd.textfiles.com/)\
`http://cd.textfiles.com/`\
Browse catalogues of historical shareware and shovelware CDs, including directory listings and links to individual files.

* [RetroArchive](http://www.retroarchive.org/)\
`http://www.retroarchive.org/`\
Browse historical software collections, CD-ROM contents and FTP archives, including indexes of files inside compressed archives.

* [Apajalista](https://www.apajalista.net/)\
`https://www.apajalista.net/`\
Search a catalogue of historical Finnish BBS software collections, including games, shareware and freeware.


## Quake Archives

Several dedicated Quake archives preserve large collections of maps, modifications, utilities and other community-created files. These are useful places to search for missing releases, find alternative copies and discover material that may not appear in general search engines.

* [Quaddicted](https://www.quaddicted.com/files/)\
`https://www.quaddicted.com/files/`\
Quaddicted maintains a large collection of Quake 1 maps, modifications and other files. Its collection also includes mirrors of historical Quake websites and FTP archives. It is particularly useful for finding maps and modifications that may no longer be available from their original websites. Explore the directory structure and look beyond the main project files for additional releases, patches and related material.

* [Shub-Hub](https://shub-hub.com/files/)\
`https://shub-hub.com/files/`\
Shub-Hub is a community archive containing a large collection of Quake-related files, including maps, modifications and other contributions. Search for known project names and filenames, but also browse the archive's categories. You may discover files that were not identified during earlier research.

* [Gamers.org](https://www.gamers.org/)\
`https://www.gamers.org/`\
Gamers.org maintains historical game archives, including mirrors of important Quake FTP collections such as idgames2 and files from PlanetQuake. Its directory structure preserves much of the original organisation of these archives. It is particularly useful for locating older releases, alternative copies and files from historical Quake hosting services.

* [Dukeworld](https://dukeworld.com/)\
`https://dukeworld.com/`, `https://dukeworld.duke4.net/`\
Dukeworld is a historical game modification and file archive, with collections covering several games, including Quake. It hosts a Telefragged archive containing files from the former Quake community hosting service. Browse its directories to find older modifications, releases, patches and other files that may no longer be available from their original websites.

* [Anders Urdal's Quake Collection](https://cloud.elkjop.no/s/158fb9c65c673ef48119d133f4d81376ab9/list/)\
`https://cloud.elkjop.no/s/158fb9c65c673ef48119d133f4d81376ab9/list/`\
A personal collection of Quake-related files shared by Anders Urdal. Browse the available directories for archived modifications and other historical material.

* [Quake Bots and Cheating Collection](https://drive.google.com/drive/folders/12sgmo96ezEeZLie6SXjUunHRW78sCzhM)\
`https://drive.google.com/drive/folders/12sgmo96ezEeZLie6SXjUunHRW78sCzhM`\
A Google Drive collection of Quake-related bots, cheats and associated files. Useful for researching bot development, cheating tools and other less commonly preserved aspects of Quake history.

* [AQ2World Files](https://files.aq2world.com/)\
`https://files.aq2world.com/`\
A file collection associated with the Action Quake 2 community. Particularly relevant for recovering Action Quake 2 modifications, maps, skins and other community contributions.

* [TastySpleen Downloads](https://tastyspleen.net/quake/downloads/)\
`https://tastyspleen.net/quake/downloads/`\
A Quake community download archive containing maps, modifications, utilities and other files. Useful for finding alternative copies of older releases and community-created content.

* [QuakeBrasil by Vegetous](https://mega.nz/folder/pZZnBLCK#fZxeV9Lwa76-CG5mdKlbVA)\
`https://mega.nz/folder/pZZnBLCK#fZxeV9Lwa76-CG5mdKlbVA`\
A collection of files from the Brazilian Quake community, preserved and shared by Vegetous. It may contain modifications, maps, utilities and other community contributions that are difficult to find in larger international archives. Browse the collection for files and releases that may not be represented elsewhere.

* [Quaketastic](https://www.quaketastic.com/)\
`https://www.quaketastic.com/`\
Quaketastic is a community file archive dedicated to Quake and its related games. It hosts a large collection of maps, modifications, source ports, tools and other community-created content. Browse its file categories and search for known project names and filenames to find releases, alternative copies and supplementary material.

* [Clan RUM Files](http://www.clan-rum.org/files/)\
`http://www.clan-rum.org/files/`\
A file archive associated with Clan RUM, containing Quake-related community files. Browse the directory for modifications, maps, utilities and other contributions that may provide additional copies of older releases or material not found in the larger Quake archives.


## Modern Quake Discussion and Forums

The Quake community remains active across several forums and discussion websites. These communities are useful for researching historical modifications, discovering files, asking questions and contacting developers, collectors and other archivists. Older discussion threads can also provide valuable evidence about releases, project histories and files that are no longer available.

* [Quake Subreddit](https://www.reddit.com/r/quake/)\
`https://www.reddit.com/r/quake/`\
A general discussion community covering the Quake series, including modifications, maps, technical questions, historical material and community projects. Useful for reaching a broad audience of Quake enthusiasts and asking about obscure files or releases.

* [Quaddicted Discussions](https://discuss.quaddicted.com/)\
`https://discuss.quaddicted.com/`\
The discussion forum accompanying the Quaddicted map archive, covering map releases, reviews, technical questions and Quake-related projects. Useful for researching modifications, finding release information and contacting community members familiar with historical Quake content.

* [Func_Msgboard](https://www.celephais.net/board/forum.php)\
`https://www.celephais.net/board/forum.php`\
One of the longest-running Quake mapping and modding discussion boards, with extensive historical discussions about level design, QuakeC programming, source ports and community projects. Particularly useful for tracing the development of maps and modifications, locating release announcements and identifying their authors.

* [QuakeOne Forums](https://quakeone.com/forum)\
`https://quakeone.com/forum`\
A long-standing Quake 1 community forum covering modifications, multiplayer servers, game clients, technical support and other topics. Although quieter than in previous years, its historical discussions can provide useful information about older releases, community projects and downloadable files.

* [Slipseer Forums](https://www.slipseer.com/index.php?forums/)\
`https://www.slipseer.com/index.php?forums/`\
A modern Quake community forum focused on single-player maps, modifications, mapping events, community projects and general discussion. Particularly useful for discovering recent releases, contacting active developers and following ongoing Quake preservation and modding activities.

## GitHub and Code Hosting

GitHub provides tools for publishing and maintaining Quake archives, sharing research, managing source code and collaborating with other archivists. It is particularly useful for hosting documentation, file indexes, research notes and scripts used to build or maintain an archive.

* [GitHub](https://github.com/)\
`https://github.com/`\
A platform for hosting Git repositories and collaborating on projects. Useful for publishing archive documentation, research notes, file inventories, preservation scripts and other resources. GitHub also supports issue tracking and contributions from the community.

* [GitHub Docs](https://docs.github.com/)\
`https://docs.github.com/`\
Official documentation for using GitHub, including creating repositories, managing files, tracking changes, accepting contributions and publishing websites with GitHub Pages. Useful for setting up and maintaining a public Quake archiving project.

* [GitHub Gist](https://gist.github.com/)\
`https://gist.github.com/`\
A simple service for publishing and sharing small collections of text files without creating a full GitHub repository. Particularly useful for preserving historical file lists, release notes, developer documentation, research findings and small scripts. Each Gist supports version history and can be updated as new information becomes available.


## Markdown Resources

Markdown is a lightweight markup language used to format plain text documents. It is particularly useful for writing archive documentation, file inventories, research notes and project websites. Markdown files are easy to create, edit and maintain, and can be read as plain text without specialised software.

* [Markdown — Wikipedia](https://en.wikipedia.org/wiki/Markdown)\
`https://en.wikipedia.org/wiki/Markdown`\
An introduction to Markdown, including its history, syntax and common uses. Includes examples of basic formatting such as headings, lists, links and images. A useful starting point for readers unfamiliar with Markdown.

* [Markdown Guide](https://www.markdownguide.org/)\
`https://www.markdownguide.org/`\
A practical guide to writing Markdown, with tutorials, syntax references and examples. Particularly useful for learning how to format documentation, create tables, insert links and organise longer documents.

* [Markdown Basic Syntax](https://www.markdownguide.org/basic-syntax/)\
`https://www.markdownguide.org/basic-syntax/`\
A concise reference covering the most commonly used Markdown formatting features. Useful as a quick reference when writing or editing archive documentation.
