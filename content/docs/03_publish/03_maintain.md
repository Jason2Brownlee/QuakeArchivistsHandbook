### **Chapter 15. Maintain and improve the archive**

An archive is not necessarily finished when it is published.

New files might be discovered, developers might provide additional information and other archivists might identify errors.

Teach the learner how to:

- Accept and evaluate contributions.
- Add newly discovered releases.
- Update the chronology.
- Correct historical information.
- Preserve new evidence.
- Record changes to the archive.
- Track outstanding research questions.
- Periodically review external links.
- Maintain backups.

Explain that archival completeness is something that can improve over time.

**Outcome:** The learner understands how to maintain an archive as an ongoing preservation project.
