### **Chapter 12. Build tools to automate research**

Teach the learner how to build small tools and scripts to assist with archival research.

advanced topic, perhaps for progammers only

Examples include:

**Download and search archived websites**

- Download archived versions of a project website.
- Extract links from HTML pages.
- Identify links to ZIP files and other downloadable artifacts.
- Search archived website content for known filenames.
- Identify links to external mirrors.
- Build lists of historical file locations.

**Analyse recovered files**

- Calculate MD5 and SHA-256 hashes.
- Identify duplicate files.
- Extract filenames and directory listings from ZIP archives.
- Read the beginning of readme files.
- Extract version numbers and dates where possible.
- Generate file inventories.
- Compare different releases.

**Create research indexes**

- Search a collection of downloaded HTML pages.
- Find references to known filenames.
- Search for developer names and project names.
- Generate lists of candidate release announcements.
- Identify potential relationships between files and releases.

The emphasis should be on building small, practical tools that save time rather than developing a large archival software system.

**Outcome:** The learner can automate repetitive research tasks and process large collections of historical material.
