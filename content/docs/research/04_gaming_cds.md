### **Chapter 7. Search CD archives and historical software collections**

Teach the learner how to investigate software distributed on magazine CDs and other physical media.

Important resources include:

- Internet Archive CD collections.
- QuakeDiscs.com.
- DiscMaster at textfiles.com.
- Other historical software and CD-ROM collections.

Explain how to search for:

- The modification's name.
- Known release filenames.
- Developer names.
- Unique filenames found inside the modification.
- Distinctive phrases from readme files.
- Other content that might appear in the modification's distribution package.

An important technique is searching for unique content rather than just the modification's name.

For example, a magazine CD might contain a modification under a generic filename such as `aq2.zip`. Searching for the project name might not find it, but searching for a unique phrase from its readme file might identify the CD's contents.

Also explain the importance of distinguishing between the original release date and the date a particular CD was distributed.

**Outcome:** The learner can identify releases preserved on physical media and recover files that might not exist on the original project website.
