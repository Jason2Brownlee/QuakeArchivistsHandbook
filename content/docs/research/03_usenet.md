### **Chapter 6. Search Usenet archives**

Introduce Usenet as a valuable source of historical information.

Explain how to use Google Groups and other surviving Usenet archives.

Search techniques include:

- Searching for the modification's name.
- Searching for known filenames.
- Searching for the names of developers.
- Searching for developer personal websites.
- Searching alternative spellings and naming conventions.
- Searching for unique filenames found inside recovered releases.
- Searching for release announcements and distribution messages.

For example, a modification might be referred to using several different names:

- Action Quake 2.
- Action Quake II.
- ActionQuake2.
- AQ2.
- Action Quake.

The same applies to filenames, developer names and project names.

Usenet can be particularly valuable because developers sometimes announced their own releases, provided changelogs, linked to homepages or described where files could be downloaded.

It can also reveal discussions about releases that are no longer available.

**Outcome:** The learner can use Usenet to discover historical announcements, developer information, filenames and distribution locations.
